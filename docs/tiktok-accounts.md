# TikTokアカウントの作り方

6アカウントを作るときの注意点と、そのまま使えるプロフィールの案です。

## 作る前に（収益化のための注意）

再生報酬（Creator Rewards Program）に参加するための条件にかかわる点です。

- **個人アカウントのまま使う**。設定の「ビジネスアカウントに切り替える」は押さない（ビジネスアカウントは再生報酬の対象外）。
- **生年月日は本当の日付で、18歳以上**。
- **1アカウントにつき、メールアドレスと電話番号が1つずつ必要**。登録の途中で「電話番号をアカウントにリンクしてください」と出て、飛ばせない（PCから登録しても、最後はスマホで電話番号を求められる）。同じ電話番号は基本的に1アカウントにしか使えない。
  - メール：Gmail なら `あなたのアドレス+history@gmail.com` のように `@` の前に `+〇〇` を付けると、同じ受信箱に届く別のアドレスとして使えることが多い。TikTok にはじかれたら、新しい Gmail を作る。収益は個人で受け取るので、会社のメールより個人のメールで作るのがおすすめ。
  - 電話番号：自分のスマホの番号がまだ TikTok に使われていなければ1つ目に使う。足りない分は povo2.0（基本料0円・SMS受信無料・eSIMで今のiPhoneに追加できる）で自分名義の番号を増やす。番号を残すには、180日に1回は一番安い有料トッピングを買う。同じ名義なら5回線までは事務手数料がかからない（6回線目からは1回線ごとに3,850円）。
  - 家族や知人の番号、「SMS受信代行」「使い捨て番号」のサイトは使わない（本人確認や乗っ取りで困る）。
- **6つとも今のうちに作っておく**（IDを確保するため）。ただし投稿は、動画を作れる4アカウント（日本史・宇宙と深海・心理学・未来の日本）から始める。都市伝説と漫画は、作り方ができてから投稿を始める。
- やってはいけないこと：フォロワーや再生数の購入、VPN、短時間での大量フォロー、同じ動画を複数のアカウントに投稿すること。

> 再生報酬の主な条件（日本）：18歳以上・フォロワー1万人以上・直近30日の再生10万回以上・個人アカウント・1分以上のオリジナル動画。
> 1人で複数のアカウントを参加させられるかは、公式の説明が見つかっていません。最初のアカウントが条件に近づいたら、TikTok Studio の「収益化」の画面で確認します。

## 作り方（スマホ）

1. TikTok アプリで1つ目のアカウントを作る（メールアドレスで登録）。
2. 2つ目からは、プロフィール画面の上の名前 →「アカウントを追加」→「新規登録」。
3. それぞれ「プロフィールを編集」から、下の表の写真・名前・ID・自己紹介を入れる。

- スマホのアプリで同時にログインしておけるのは3つまでという情報が多いです。4つ目以降は、ログアウトして入れ替えるか、PCのブラウザ（https://www.tiktok.com/tiktokstudio ）でログインしてください。
- IDは30日に1回しか変えられません。名前は7日に1回変えられます。

## プロフィールの案

写真は画像生成AIで作ります。プロンプトは [icon-prompts.md](icon-prompts.md) にあります（TikTok では丸く切り抜かれます）。`assets/profile-icons/` の写真は、プログラムで作った仮のものです。

## AIで作った動画の表示

- **都市伝説（全編AI映像）**：投稿のときに「AI生成コンテンツ」の表示をオンにする（本物そっくりのAI映像には表示が必要）。
- **ポリゴン調の3D・モーショングラフィックス**：本物と見間違える映像ではないので、表示は必須ではありません。画面に「CGによる再現」と出しています。ナレーションには「VOICEVOX:キャラ名」のクレジットが入ります。
