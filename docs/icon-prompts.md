# プロフィール画像のプロンプト（画像生成AI用）

最初に「共通のコンテキスト」を貼ってから、アカウントごとのプロンプトを1つずつ貼ります。
プロンプトは1つだけ貼っても通じるように、大事な条件をそれぞれに入れてあります。

## 共通のコンテキスト

```
これから、TikTokで運用する6つのアカウントのプロフィール画像を1枚ずつ作ります。
6つはジャンルも雰囲気もまったく違うので、画風はアカウントごとに変えてください。

【共通のルール】
・用途はTikTokのプロフィール画像。丸く切り抜かれ、スマホでは直径40〜100pxほどの小ささで表示される
・正方形（1:1）。主役は1つだけにして、中央に大きく置く。円で切り抜いても欠けないよう、周りに余白をとる
・小さく表示しても何の絵か一目で分かるように、形ははっきり、色数は少なめ、背景はシンプルにして主役とのコントラストを強くする
・文字・ロゴ・サイン・透かしは入れない
・実在の人物、既存のキャラクター、企業や店のロゴ、特定できる実在の場所は描かない
```

## 1. 知られざる日本史

**コンテキスト**：教科書には載らない日本史の謎や意外な真実を、1分強の短編ドキュメンタリーで語る。20〜40代の歴史好き・雑学好き向け。落ち着いた語りで、謎と余韻を残す。テーマカラーは朱色。

```
TikTok「知られざる日本史」のプロフィール画像。
日本の木版画（浮世絵）のような絵柄。墨の黒・朱色（#ff6a3d）・金の3色を中心に、背景は生成りの和紙の質感。
中央に、大きな朱色の夕日を背にした日本の城の天守の黒いシルエット。城の下半分は屏風絵のような金色の雲（すやり霞）に隠れていて、「まだ知られていない歴史」を感じさせる謎めいた雰囲気。
正方形、主役は中央に大きく、丸く切り抜いても欠けない余白。細かい描き込みは控えめ。文字・ロゴは入れない。
```

```

背景は黒に近い濃紺で、霧がうっすら漂う。色は黒・白・暗い赤だけ。血やグロテスクな表現は入れない。

## 3. 宇宙と深海のふしぎ（続きもの「深海8000mからの生還」）

**コンテキスト**：水深8000mで動けなくなった潜水艇「うみつばめ号」のパイロット見習い・ナギ（19歳・オレンジのパイロットスーツ）の生還を描く続きもの。毎話の最後に、ナギの次の行動を視聴者がコメントで決める。動画はポリゴン調の深海で、深い青と黒に、ライトや発光生物を水色・黄色で目立たせる。テーマカラーは黄色。

続きものにしたあとのプロフィール画像：

```
TikTokの続きもの物語「深海8000mからの生還」のプロフィール画像。
真っ暗な深海に、小さな潜水艇が1機だけ浮かんでいる。潜水艇の丸い窓から黄色（#ffcf3f）の明かりがもれ、窓の中にオレンジ色のパイロットスーツを着た人影が小さく見える。
潜水艇の前のライトが、下に向かって細く光の筋をのばしている。周りには青く光る小さな発光生物とマリンスノーが少しだけ漂う。
少しローポリ（角ばったポリゴン）の質感がある、静かで緊迫感のあるデジタルアート。
正方形、潜水艇は中央に大きく、丸く切り抜いても欠けない余白。文字・ロゴは入れない。
```

続きものにする前のプロフィール画像：

```

少しローポリ（角ばったポリゴン）の質感がある、透明感のあるデジタルアート。

## 4. 深夜コンビニ物語

**コンテキスト**：深夜のコンビニで働く大学生「ミナト」と、毎晩やってくるクセの強い常連客たちの1話完結ショート漫画。笑い・ちょっと泣ける・ちょっと不思議、のどれかでオチをつける。10〜30代向け。白黒の漫画のコマに、夜のコンビニの蛍光灯の色を差し色にする。テーマカラーは黄色。
**このアイコンのミナトが、今後の漫画動画のキャラクターの見た目の基準になります。**

```
TikTok「深夜コンビニ物語」のプロフィール画像。主人公ミナトの顔のアップ。
日本の白黒漫画の絵柄（Gペンの線、スクリーントーン）で、色は蛍光灯の黄色（#ffd84a）だけを差し色に使う。
ミナトは20歳の大学生の男性。黒髪で少し寝ぐせのはねた髪、眠そうだけど優しい目で、ゆるく笑っている。無地の店員用エプロンを着ている（実在のコンビニを思わせる色・ストライプ・ロゴは入れない）。
背景はぼかした夜のコンビニのレジまわりで、黄色い蛍光灯の光が後ろから差している。
正方形、顔は中央に大きく、丸く切り抜いても欠けない余白。文字・吹き出し・ロゴは入れない。
```

線はやわらかく、影はほとんどなし。色はベージュ・青緑・黄の3色だけ。

## 6. 20XX年の日本

**コンテキスト**：公的統計や研究機関の予測データをもとに「〇年後の日本」を、ポリゴン調の町とグラフで見せる。20〜40代のビジネス・社会問題に関心がある層向け。冷静で分かりやすく、不安をあおらず前向きな視点も添える。テーマカラーはシアン（水色）。

```
TikTok「20XX年の日本」のプロフィール画像。
深い紺色（#071431）の背景に、日本列島の形が無数の小さな光の点とデータのグリッドで描かれている。光はシアン（#3fd2ff）で、都市のあたりほど明るく輝く。列島の上を、なめらかな折れ線グラフの光の線がひとすじ横切り、右上の未来へ伸びていく。
近未来的で落ち着いた、データビジュアライゼーション風のデジタルアート。不安をあおる暗さではなく、静かで前向きな雰囲気。
正方形、日本列島は中央に大きく、丸く切り抜いても欠けない余白。文字・数字・ロゴは入れない。
```

## うまく作るコツ

- 1回で決めずに3〜4枚作り、スマホで画像を小さくして見ても何の絵か分かるものを選ぶ。
- 直したいときの言い方：「もっとシンプルに」「主役をもっと大きく」「背景をもっと暗く」「色数を減らして」。
- 日本列島の形がおかしいときは「日本列島の形を地図どおり正確に」と足す。
- 深夜コンビニ物語のミナトは今後の漫画のキャラクターの基準になるので、決まった画像は保存しておく。
