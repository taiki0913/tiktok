# BGM の置き場所

アカウントごとのフォルダに入っている曲から、動画を作るたびに1曲が選ばれます（音量はナレーションの邪魔にならないよう小さくしています）。

最初から入っている曲は、`scripts/bgm/generate_bgm.py` でプログラムが作曲したオリジナル曲です。
利用規約の確認やクレジット表記は不要で、著作権の申し立てを受ける心配もありません。

| フォルダ | アカウント | 曲調 |
|---|---|---|
| `history/` | 知られざる日本史 | 和の音階（都節）の琴と持続音 |
| `cosmos/` | 宇宙と深海のふしぎ | ゆっくり移り変わる和音と鐘の音 |
| `future/` | 20XX年の日本 | 控えめなアルペジオとリズム |
| `psychology/` | 心理学のあるある | やさしいエレピ |
| `urban_legend/` | 夜更けの都市伝説 | 不穏な持続音・風・オルゴール |
| `manga_story/` | 深夜コンビニ物語 | 軽いマリンバとピチカート |

## 場面の雰囲気ごとに切り替える曲（続きもの）

`<アカウント>/moods/` に曲があるアカウントは、台本エージェントが場面ごとに選んだ雰囲気に合わせて、BGM を切り替えます（境目はクロスフェード。5秒未満の短い切り替えはしません）。
いまは宇宙と深海のふしぎ（続きもの「深海8000mからの生還」）に入っています。

| ファイル | 雰囲気 | 曲調 |
|---|---|---|
| `moods/calm.mp3` | 静か・落ち着き | 浮遊感のある和音と、まばらな鐘 |
| `moods/wonder.mp3` | 美しさ・神秘 | 明るい和音ときらめく鐘 |
| `moods/tension.mp3` | 緊迫・不安 | ぶつかり合う低い音と、心臓の鼓動のようなリズム |
| `moods/danger.mp3` | 危険・急ぐ | 速く刻む低音と強い和音、警報のような高い音 |
| `moods/sad.mp3` | 切ない・孤独 | ゆっくりのエレピと、まばらな旋律 |
| `moods/hope.mp3` | 希望・前向き | 明るい和音と上がっていくアルペジオ |

同じ雰囲気の曲を増やすときは、`tension-2.mp3` のように「雰囲気-番号」の名前で入れると、動画ごとにどれか1曲が選ばれます。

好きな曲を足したいときは、商用利用できる音源（mp3・wav・m4a・aac・ogg）を同じフォルダに入れてください。
その場合は、配布元の利用規約（商用利用・クレジット表記の要否）を必ず確認してください。
