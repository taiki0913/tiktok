# BGM の置き場所

アカウントごとのフォルダに入っている曲から、動画を作るたびに1曲が選ばれます（音量はナレーションの邪魔にならないよう小さくしています）。

最初から入っている曲は、`scripts/bgm/generate_bgm.py` でプログラムが作曲したオリジナル曲です。
利用規約の確認やクレジット表記は不要で、著作権の申し立てを受ける心配もありません。

| フォルダ | アカウント | 曲調 |
|---|---|---|
| `history/` | 知られざる日本史 | 和の音階（都節）の琴と持続音 |
| `cosmos/` | 宇宙と深海のふしぎ | ゆっくり移り変わる和音と鐘の音 |
| `future/` | 20XX年の日本 | 控えめなアルペジオとリズム |
| `psychology/` | 心理学のあるある | やさしいエレピ |
| `urban_legend/` | 夜更けの都市伝説 | 不穏な持続音・風・オルゴール |
| `manga_story/` | 深夜コンビニ物語 | 軽いマリンバとピチカート |

好きな曲を足したいときは、商用利用できる音源（mp3・wav・m4a・aac・ogg）を同じフォルダに入れてください。
その場合は、配布元の利用規約（商用利用・クレジット表記の要否）を必ず確認してください。
