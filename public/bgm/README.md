# BGM の置き場所

アカウントごとのフォルダに、商用利用できるフリー音源（mp3・wav・m4a・aac・ogg）を2〜3曲入れてください。
動画を作るたびに、そのフォルダからランダムに1曲選ばれます（音量はナレーションの邪魔にならないよう小さくしています）。

| フォルダ | アカウント |
|---|---|
| `history/` | 知られざる日本史 |
| `cosmos/` | 宇宙と深海のふしぎ |
| `future/` | 20XX年の日本 |
| `psychology/` | 心理学のあるある |
| `urban_legend/` | 夜更けの都市伝説 |
| `manga_story/` | 深夜コンビニ物語 |

音源ファイルは Git には入りません（ライセンスの都合で、各PCに置く）。
使う音源の利用規約（商用利用・クレジット表記の要否）は、必ず配布元で確認してください。
